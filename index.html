Se actualiza sola tras cada cierre de mes: GitHub Actions descarga las cotizaciones de Yahoo Finance, calcula la señal en dólares con el mismo motor que el Excel y publica esta página. Tras cada cierre de mes, la operación se hace el primer día hábil: mantener si el primero no cambia, o vender el anterior y comprar el nuevo. La señal de cada decisión usa cierres hasta el final del mes anterior, así que la próxima rotación ya es definitiva un mes antes; el avance provisional enseña cómo va la siguiente con los precios de cada día. Festivos de mercado no contemplados salvo el 1 de enero. Herramienta de cálculo, no recomendación de inversión.
